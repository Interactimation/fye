# Writing Tools

In this course I hope to give you some writing tools you can use for the whole of your college career and beyond!

## Github Repos
[GitHub Repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories) are places to store and track changes to documents, usually this means computer code but it can include text, images and other files

## Markdown
[Markdown](https://www.markdownguide.org/cheat-sheet/) is a simple way to add formatting like:

### Headers
**Bold Text**\
_Italics_

* and
* lists
* to [plain text](https://en.wikipedia.org/wiki/Plain_text)

-using standard keyboard symbols, such as * _ and #

One of the remarkable things about markdown is that it can become formatted text in any kind of document you might want, like Word, PDF, even a website!

## GitHub Pages
[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) is a free service where GitHub will host and present your Markdown documents as free websites
